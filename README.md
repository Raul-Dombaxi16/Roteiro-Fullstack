# ☕ Cafetaria Website

Um website desenvolvido para uma cafetaria, pensado para apresentar o espaço, os seus produtos e proporcionar aos visitantes uma forma simples e agradável de conhecer o estabelecimento.

## Sobre o projeto

A ideia deste projeto é criar uma presença online para uma cafetaria, com um design acolhedor, uma navegação simples e uma identidade visual que combine com o ambiente de um café.

Mais do que apresentar produtos, o objetivo é transmitir um pouco da experiência que os clientes podem encontrar no estabelecimento.

## O que estou a desenvolver

- Uma página inicial com uma apresentação da cafetaria.
- Uma secção dedicada aos produtos.
- Informações sobre o estabelecimento.
- Área de contactos e redes sociais.
- Um layout adaptável a diferentes tamanhos de ecrã.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
